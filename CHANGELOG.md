## [1.0.0]

### Added

- Jogo de adivinhação executado no terminal.
- Geração aleatória do número secreto.
- Modo determinístico para testes.
- Validação de entradas e limites personalizados.
- Controle de tentativas.
- Dicas para palpites maiores ou menores que o segredo.
- Mensagens motivadoras durante a partida.
- Mensagens de encerramento por vitória ou derrota.
- Testes automatizados com `unittest`.
- Pipeline de integração contínua com GitHub Actions.
- Documentação do projeto e fluxo de contribuição.
