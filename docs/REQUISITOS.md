# Rastreabilidade do projeto

## Requisitos originados no PDF m10_a55.pdf
- Jogo de terminal com segredo fixo (para testes) ou aleatório.
- Dicas maior/menor e limite de tentativas.
- Entradas inválidas não derrubam o jogo.
- Mensagens motivadoras.
- Uso de variáveis, condicionais, while e funções.
- Extras: seleção de intervalo, dificuldade, histórico e replay.

## Processo adicional para aprender engenharia de software
- Git, branches, Conventional Commits e Pull Requests.
- Issues com critérios de aceitação.
- Testes automatizados via unittest e GitHub Actions.
- Versionamento após concluir o MVP.

O desafio original não exige GitHub, PR ou CI: são ferramentas de aprendizagem incluídas neste projeto.
